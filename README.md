🚗 Vehicle License Plate Identification System (VLIS)

A real-time AI-powered system that automatically detects and recognizes vehicle license plates from images, video, and live streams.

Built with Deep Learning + Computer Vision, this project demonstrates end-to-end expertise in AI, OCR, and GUI development.

🔥 Highlights

YOLOv8 (Ultralytics) → High-speed & accurate license plate detection

EasyOCR → Robust text recognition across formats & lighting conditions

OpenCV → Image processing, frame handling, and visualization

Tkinter GUI → User-friendly interface for non-technical users

SORT Tracking → Assigns unique IDs, avoids redundant recognition

Logs & Cropped Plates → Saves results with timestamps for verification

🌟 Why It Stands Out

✅ Real-time performance with multiple input types (video, live, IP stream)
✅ Modular design → easily extensible for database & cloud integration
✅ Industry use cases → traffic monitoring, toll booths, parking automation, security systems
✅ Demonstrates strong skills in AI, ML, Computer Vision, and System Design

🛠️ Tech Stack

Python 3.x

YOLOv8 (Ultralytics) – Object Detection

EasyOCR – Optical Character Recognition

OpenCV – Image Processing

Tkinter – GUI Development

SORT (Kalman Filter + Hungarian Algorithm) – Vehicle Tracking
